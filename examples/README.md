# Examples

`synthetic_regions.csv` is a **fully synthetic** regional-economics table generated by
`make_synthetic_economics.py` (seeded, standard library only). Every value is invented; it describes no real
region, person or firm and carries no licensing constraints beyond the repository license.

- `plans/*.json` – one example plan per operation (Inspect, Relate with Pearson and Spearman, Compare, Cluster).
- `run_example.py` – runs a plan and prints the canonical JSON result (a library demonstration, not a CLI product).
- `profiles/synthetic_regions.json` – the explicit CSV profile of the example table, for `python -m axiom analyze`.

```bash
uv run python examples/run_example.py examples/plans/compare.json
```

The synthetic data have no meaning beyond exercising the engine. Results computed from them are not findings.
