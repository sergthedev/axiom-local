## Notices for adapted dataset text (AXBENCH-TR)

**Cognipeer/synthetic-text-to-sql-tr** (Apache-2.0), a Turkish translation of **gretelai/synthetic_text_to_sql**
(Apache-2.0). Licence: https://www.apache.org/licenses/LICENSE-2.0 (full text: `data/axbench-tr/LICENSES/Apache-2.0.txt`).
Changes made here: request sentences were selected by a rule that keeps only a plain average, minimum or maximum
question (or a request to change data), paired with a schema read from the synthetic `CREATE TABLE` context; gold
labels were derived by rule; no SQL is used or emitted. The files are in `data/axbench-tr/v0.2-rev1/` and the
v0.2-draft record. No copyright holder is named on either dataset card. The Gretel README states Apache 2.0 for
data made with Gretel Navigator; the terms of the model behind that generation were not checked.

**AlicanKiraz0/Turkish-Finance-SFT-Dataset**: quarantined (the Hub tag says MIT, the README badge says Apache-2.0,
no copyright holder is named). Only the superseded v0.2-draft contains questions from it. Nothing from it is in
v0.2-rev1, and no MIT notice is claimed. It stays unused until the conflict is resolved with the publisher.

**İzmir Büyükşehir Belediyesi Açık Veri Portalı** (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/):
the CSV files under `data/axbench-tr/economic/izmir/` are unmodified copies (full licence text: `data/axbench-tr/LICENSES/CC-BY-4.0.txt`); the table-name and column-name inventory is derived from them. One file with contact details was removed after the privacy audit (`economic/PRIVACY_AUDIT.json`).

The licence evidence read for each source (page, SHA-256, excerpt) is in
`data/axbench-tr/sources/LICENCE_EVIDENCE.json` and `data/axbench-tr/DATA_SOURCES.md`.
