# v0.2-draft (superseded, kept unchanged)

The first AXBENCH-TR corpus (8,625 records), accepted by the technical review as acquisition evidence only.
It is **not** to be used for training: its adapted plans were derived from SQL shape (including SUM, filters
and rankings) and its split checks covered template records only. `../v0.2-rev1/` replaces it. The files here
keep their original bytes and hashes (`MANIFEST.json`); the current code no longer reproduces them, and a test
checks that they are unchanged. Its review sample under `review/` is superseded as well.
